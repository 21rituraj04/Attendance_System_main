# 🎓 AttendX - Premium University Attendance & ERP System

AttendX is a sophisticated, enterprise-grade University ERP and Attendance Management System designed to streamline academic operations. Built with a focus on **Premium UI/UX**, it provides a seamless experience for Administrators, Teachers, and Students.

---

## ✨ Key Features

### 🏛️ Admin Portal (The Command Center)
- **Comprehensive Management**: Oversee Students, Teachers, and Departments with ease.
- **Audience-Targeted Notices**: Send official announcements specifically to Teachers, Students, or entire Departments.
- **Live Monitoring**: Real-time tracking of attendance across the faculty.
- **Secure Operations**: Built-in "Confirm-to-Delete" workflows for data integrity.

### 👨‍🏫 Teacher Portal
- **Effortless Attendance**: Quick and intuitive interface for marking student attendance.
- **Notice Board**: View administrative notices and send class-specific messages to students.
- **Analytics**: Track class performance and attendance trends.

### 🎓 Student Portal
- **Personal Dashboard**: View individual attendance percentages and academic progress.
- **Integrated Notifications**: Receive real-time notices from both Admin and Teachers.
- **Responsive Design**: Access your dashboard from any device, anywhere.

---

## 🎨 Design Aesthetics

AttendX isn't just functional; it's **beautiful**.
- **Glassmorphism**: Modern, frosted-glass UI elements for a premium feel.
- **Framer Motion**: Fluid, physics-based animations for smooth transitions.
- **Dark Mode Optimized**: Sleek, high-contrast themes for better readability.
- **Responsive Layouts**: Fully optimized for Desktop, Tablet, and Mobile.

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite, Vanilla CSS (Premium Custom Styles)
- **Animations**: Framer Motion, Lottie-React
- **Icons**: Lucide-React / FontAwesome
- **Backend**: Node.js, Express (assuming based on folder structure)
- **Database**: MongoDB / SQL (Standard ERP choice)

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm / yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ppourel/attendance_system.git
   ```

2. **Setup Frontend**
   ```bash
   cd attendance-app
   npm install
   npm run dev
   ```

3. **Setup Backend**
   ```bash
   cd ../attendance-backend
   npm install
   npm start
   ```
